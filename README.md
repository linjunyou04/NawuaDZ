# 我功夫特牛 · 网页复刻版（NawuaDZ）

纯前端 HTML5 Canvas 复刻的单指格斗小游戏——奶蛙大战美团外卖小狗。

## 在线游玩

开启 GitHub Pages 后访问：`https://linjunyou04.github.io/NawuaDZ/`

## 玩法

- 点击屏幕左/右侧出招（或 ← → / A D），按住不放可跑路
- 三段连招自动循环：男＝手刀→头锤→冲膝 / 女＝回旋踢→高踢→扫堂腿
- 打不过就跑！跑路时留意屏幕外的**眼罩奇遇**
- 每波清空后三选一强化，每 5 波 BOSS 登场，10 波后怪潮指数级增长

## 结构

```
index.html      游戏本体（单文件，零依赖）
assets/         角色素材 + 语音包（assets/sfx/）
tools/          素材处理脚本（抠图/去水印）
素材/            原始素材归档
```
